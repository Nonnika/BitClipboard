# BitClipboard

一个轻量的原生 macOS 菜单栏剪贴板管理器。使用 SwiftUI + AppKit，无第三方依赖，无服务器。

## 启动

需要 macOS 13 或更新版本，以及 Xcode 或 Swift 命令行开发工具。

```sh
./scripts/build.sh
open dist/BitClipboard.app
```

也可以把 `dist/BitClipboard.app` 拖入“应用程序”文件夹，再启动。应用只显示在屏幕顶部的菜单栏，不显示 Dock 图标。登录启动建议安装到“应用程序”后再开启。

点击剪贴板图标，或按 **Control + Option + V** 打开历史面板。点击任意记录，把内容放回系统剪贴板，再到目标应用按 **Command + V** 粘贴。**Command + 1–9** 复制当前筛选结果的前九项。点击右上角搜索按钮或按 **Command + F** 打开搜索浮层，输入后按回车收起；再次打开搜索并清空输入即可恢复完整列表。右键记录可以收藏、查看完整内容或删除。

点击面板外部区域或切换至其他应用时，面板会自动隐藏，记录仍会继续。面板内部的搜索、右键菜单和设置操作不受影响。

鼠标悬停在记录上时，按 **空格** 打开完整文字或图片预览；再次按空格或 **Esc** 关闭。搜索框输入空格、其他窗口中的键盘操作和带修饰键的空格组合不会触发预览。

## 功能

- 自动记录启动之后复制的纯文字、图片和 HTTP/HTTPS 链接；单张图片文件复制后会转成独立保存的图片，其他文件和文件夹不记录，多文件选择不记录。
- 搜索内容与来源应用，按类型筛选，查看完整文字与图片。
- 正则提取文本中的数字及 HTTP/HTTPS、www 链接，在记录底部显示标签；点击标签仅复制该数字或链接。保留前导零、小数、百分比和正负号，相同结果去重，链接内部的数字不重复提取；标签较多时可横向滚动。
- 链接会区分域名与后面紧跟的中文说明，如 `https://blog.alphazero.top测试` 只提取网址；中文路径、查询参数和国际化域名保留。网址与说明混合的内容按文字分类，完整复制仍保留全部原文。
- 图片直接显示预览，统一使用 8 pt 连续圆角，最大高度 160 pt，超出可用宽度或高度时等比例缩小，小图不放大。
- 列表图片在后台生成最长边 800 像素的缩略图，使用 32 MiB 缓存；图片离屏后释放卡片持有的位图。正则提取也在后台执行，长文本卡片仅排版前 600 个字符，复制与完整预览仍使用原内容。
- 相同内容去重并更新到最近位置，收藏置顶，单条删除。
- 默认保存最近 200 条未收藏记录，可改为 100、500 或 1,000 条；收藏不计入上限。
- 菜单中的暂停记录、清空未收藏记录，以及设置中的登录启动。
- 使用黑白强调色，跟随系统浅色／深色外观，面板仅保留顶部工具栏和内容列表。
- 删除、筛选和收藏排序使用 0.3 秒贝塞尔曲线过渡：剩余记录平滑移位，新内容轻微上移淡入，分类选中背景随之滑动；开启减少动态效果时关闭这些位移动画。
- 空历史显示“你还没有复制任何内容”，背景使用淡灰色波纹动画；系统开启减少动态效果时显示静态波纹。

## 存储与边界

历史保存至 `~/Library/Application Support/BitClipboard/history.json`，图片保存在同目录的 `Images/` 中。历史在重启后恢复，清除记录会同时删除对应图片。图片文件会读取实际图像并以 PNG 保存，重新复制时提供图像数据，原文件移动或删除不影响历史图片。文本以纯文字重新复制，不保存富文本格式。

旧版文件历史在首次加载时迁移：仍可读取的单张图片文件转为独立图片，保留收藏和复制时间；其他文件记录及无法读取的图片引用从历史移除。迁移仅处理历史记录，原文件保持不变。

应用每 0.6 秒检查一次系统剪贴板。非常快速的连续复制可能只捕获最后一次；超过 25 MiB 的原始图片数据及超过 2 MiB 的文字会跳过。启动时不读取已有剪贴板，暂停期间的内容也不会在恢复记录时补录。

不会联网或上传内容。带 `org.nspasteboard.ConcealedType`、`TransientType` 或 `AutoGeneratedType` 标记的内容会被忽略；未带敏感标记的密码仍可能被记录。可在处理敏感信息时暂停，并随时删除历史。数据没有额外加密，依赖当前用户目录权限及系统磁盘保护。

当前构建脚本生成本机架构的应用并使用本地临时签名。公开分发时需要 Developer ID 签名和 Apple 公证。全局快捷键不需要辅助功能权限；若被其他应用占用，可继续使用菜单栏图标。

## 开发与测试

```sh
./scripts/test.sh
```

可以用 Xcode 打开 `Package.swift`。`Sources/BitClipboardCore` 包含数据模型、持久化和剪贴板解析；`Sources/BitClipboard` 包含菜单栏生命周期、监控和 SwiftUI 界面。测试使用独立临时目录与独立剪贴板，不修改真实剪贴板或用户历史。
